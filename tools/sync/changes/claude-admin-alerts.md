The admin reads the Alerts tab (ROADMAP "Security follow-ups", Pierre, 2026-11-01: "show the Alerts tab in the admin"): `readAlerts` (admin token only, as `readEvents`) serves its last 3000 lines, newest first, each as its time and text; a line of the per-name answer cap (`n:<name>`) is served with the name's admin id in place of the name, so the admin page shows no name. The tab itself is not changed.
