**How to read the tables.**

- **State**: Done, Partly done, Decided (agreed, not started), Waiting for Pierre, Waiting (on data or a third party),
  Idea (only considered), Obsolete (superseded).
- **Horizon**: Short (days), Medium (weeks), Long (months). Taken from the docs where they say it, else my reading
  (marked "my reading" where it matters).
- **Size**: the rough scale of the work, S (one small PR), M (a few PRs), L (a series of PRs). It carries no duration.
  The two last columns of every table in section 4 give the measured time instead (rule W11):
  - **Type, size band** (my reading, from the files the item will touch): the type is the one `tools/effort.py`
    gives a merged PR touching those files (engine for `core.js`, `model.js`, `quiz.js`; sheet for `Code.gs`; admin;
    feature for the other app files; content for data; tooling for `tools/`, `tests/`, workflows; docs; study). The band
    is the lines changed, as the tool counts them: XS up to 20, S up to 100, M up to 400, L up to 1,500, XL above.
  - **Measured agent time**: `python3 tools/effort.py --estimate TYPE BAND`, copied as it prints: the five merged PRs
    closest in type and size, and their median and 25-75% range, from the branch's first commit to green checks. For an
    L item (a series of PRs) it is the figure for one PR of the series. Nothing is multiplied by a number of PRs.
  - **Bulk work run by a light model** (a judging or framing pass over N photos, a refill, a watermark pass) gets no
    figure: the measured PRs are code PRs, and bulk work depends on the batch size. Items that are Pierre's hands, or
    obsolete, get none either.
  - The band is a guess of mine and the tool's sample is small for some types (study: five PRs, the same for every
    band): read the figure as an order of magnitude and the cited PRs as the evidence.
- Each item appears once, in the theme it belongs to most. Other docs that name the same item are listed in its "Recorded
  at" cell.
- Done work with nothing left is not listed, except where a doc still calls it open (section 3).
